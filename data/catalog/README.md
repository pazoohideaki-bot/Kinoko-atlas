# 確認記録カタログ

公開用の原本は、従来18件を保持したルート index.html と、このディレクトリの JSON の places 配列です。scripts/build.py が両者を統合し、修正済み UI を注入して dist を生成します。公開データは dist/data/places.json と dist/build.json にも出力します。dist は生成物であり直接編集しません。

2026-10-06に東京都内4地点と富士山静岡側の広域記録1件を追加。2026-10-08に山梨県内3市町と軽井沢町の検査記録4件を追加しました。新しい合法採取可能地点を確認したという意味ではありません。入山鑑札の手続参考は reference_only_not_mapped に分離し、一般採取許可と解釈しません。

更新時は現在の main、既存18件、全 catalog JSON を読み、同じ地点・同じ記録の重複を防ぎます。追加は schema_version=1、reviewed_at、places を備えた JSON に行い、既存レコードの変更はそのレコードを持つ原本で行います。同一IDを別のJSONに追加するとビルドは失敗します。

確認日・掲載日・標本採取日を区別してください。今回の新規レコードの months は確認された月であり、発生期全体や現況保証ではありません。標高・植生・実座標が非公表または未確認なら、そのまま明記し推測で補完しません。公園や広域資料の代表点を、発生木や採取ルートの正確な位置として扱わないでください。

一般客の採取権が確認できない記録は青、明示された採取禁止は赤です。観察会の参加費・入園料・入山券だけから一般採取権を推測しません。出荷制限、採取・摂取の自粛、土地の権利、食用同定を別の情報として管理します。検査値の『未満』をゼロへ変換しません。食用種の名前の一致は、個体の安全の保証ではありません。

UIのCSS・JSは内容追加のたびに変更しません。既存の公開前・公開後ブラウザテストを通し、build.json の件数・データ日付と公開データを照合してから、画面反映済みと報告します。
